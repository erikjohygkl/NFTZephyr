# NFTZephyr

NFTZephyr is a high-performance, real-time data processing engine that scales dynamically on-demand.

The key benefits of using NFTZephyr include:

- NFTZephyr is a high-performance, real-time
- data processing engine that scales
- dynamically on-demand

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NFTZephyr.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NFTZephyr is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
